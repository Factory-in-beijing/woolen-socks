# ADR-0002 — პლატფორმის ბირთვი (shared kernel) ბექენდში

სტატუსი: მიღებულია · თარიღი: 2026-11-10 · წყარო: Architecture v6 + Visual Guide (პრინციპები 2, 6–9, 13–15, 18–20)

## კონტექსტი

ყველა მოდული (M1–M8) ერთსა და იმავე ცოცხალ ნაწილებს საჭიროებს: ვინ არის გამომძახებელი და რა შეუძლია, ორმაგი დაჭერის დაცვა, ტრანზაქციაში ჩაწერილი ფონური job, ფული, სტატუსის გადასვლები. ეს `apps/api/src/shared`-ში ერთხელ იწერება, რომ მოდულებმა მხოლოდ ბიზნეს-წესები დაწერონ.

## დამატებები დოკუმენტის სიაზე

- `idempotency_conflict` (409, non-retryable) — შეცდომის კოდი; მხოლოდ დამატება. ენა/ტექსტი: `ka.errors`.

## გაუგებრობები / დაშვებები (არა პროდუქტის წესი)

- `IDEMPOTENCY_TTL_HOURS=24`, `JOB_LEASE_SECONDS=300`, `JOB_SWEEP_*`, sweeper-ის cron `*/5 * * * *` — **სამუშაო დაშვებებია** env/Terraform ცვლადებში, load-ტესტით/მონიტორინგით დასაზუსტებელი.
- `JOB_MAX_ATTEMPTS=8` უნდა ემთხვეოდეს Cloud Tasks queue-ს `max_attempts`-ს (Terraform).
- გაშვების მასშტაბი: v6 (10 000 ერთდროულად) vs Visual Guide (≈20 000 პიკზე) — ღიაა; `load/peak.js` პარამეტრულია.

## ვერ გადამოწმდა ამ გარემოში

Cloud Tasks-ის რეალური გაგზავნა და retry, Scheduler-ის OIDC, `google_firestore_field` TTL-ის გააქტიურება, log-metric/alert (Terraform მხოლოდ `validate`-ზეა გავლილი); Firestore-ის composite index-ის აუცილებლობა (ემულატორი ინდექსებს არ ამოწმებს — `firestore.indexes.json`-ში `jobs` ინდექსი ხელითაა დამატებული).
